# 🚀 Planify Pro

A modern productivity and task management application built with **React**, **Vite**, and **Chart.js**.

---

## ✨ Features

- 📋 Task Management
- ✅ Complete / Undo Tasks
- ✏️ Edit Tasks
- 🗑 Delete Tasks
- 🔍 Search Tasks
- 🎯 Priority Levels
- 📅 Due Dates
- 📂 Categories
- 📊 Analytics Dashboard
- 📈 Productivity Score
- 🌙 Dark Mode
- 💾 Local Storage
- 📱 Fully Responsive

---

# Installation

```bash
npm install
```

Run development server

```bash
npm run dev
```

Create production build

```bash
npm run build
```

Preview production build

```bash
npm run preview
```
